# AstroGuide AI

Personalized astrology reflection experience.

## Features
- Responsive cosmic UI
- Career, love and personal growth readings
- Vercel serverless API
- Input validation and loading states

Open `index.html` locally or deploy with Vercel.

## Multi-tradition knowledge
See [KNOWLEDGE.md](KNOWLEDGE.md) for the interpretation framework covering Vedic Jyotish, Lal Kitab, Samudrika Shastra and Bhrigu traditions.


## Free astronomy engine plan
The project will use an MIT-licensed JavaScript astronomy engine for calculated planetary positions, with traditional astrology interpretations clearly separated from the astronomical data.
